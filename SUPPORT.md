# Support

Use the following channels:

- Bug reports: open a GitHub issue with the bug report template.
- Feature requests: open a GitHub issue with the feature request template.
- Usage questions: open a GitHub Discussion if discussions are enabled, or an
  issue with a minimal reproducible example.
- Security reports: follow [SECURITY.md](SECURITY.md).

For faster help, include:

- `tscv-vision` version
- Python version
- Operating system
- Installation method
- Minimal input shape and command or code snippet
- Full traceback, if there is an error
