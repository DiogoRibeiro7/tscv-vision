# Synthetic pilot run

This directory is a committed harness smoke artifact, not empirical evidence for
encoder accuracy. The datasets are generated by
`tscv_vision.evaluation.make_synthetic_dataset` only to prove that the full
benchmark grid writes resumable raw rows, a manifest, and a statistical summary.

Recreate it from the repository root:

```bash
python -m tscv_vision.evaluation --synthetic \
    --synthetic-datasets 5 --synthetic-length 32 --synthetic-n-per-class 6 \
    --seeds 0 1 2 --out results/pilot-synthetic --no-resume
```

Grid:

- 5 generated datasets: `Synthetic0` through `Synthetic4`
- 8 default methods from `evaluation.DEFAULT_METHODS`
- 3 seeds: `0`, `1`, `2`
- 120 rows in `results.csv`
